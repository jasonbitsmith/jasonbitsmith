# 在 X 上发中文长文，终于不用再和排版较劲了

逛 X 的时候，很多人刷到的中文长帖，其实都经历过同一套折磨：

空格一会儿有一会儿没有，中英文挤在一起；标点一会儿全角一会儿半角；想分段却总是挤成一坨；好不容易写长了，又得自己算字数、自己拆线程，还要预览一眼发出去会不会很难看。

写完一长段，再改成适合 X 阅读的样子，往往比想内容还累。

所以我做了一个免费 Chrome 插件：**推文排版 TidyPost**。

它直接挂在 X 网页版的发帖框旁边，帮你把「整理 → 预览 → 拆线程 → 写回发帖框」这条链路走完。草稿留在本地，不上传。

商店链接：https://chromewebstore.google.com/detail/hngllgbockoahjngmhjcddcnnggjifba

---

## 它解决的，就是发帖那几分钟里最烦的事

### 1. 一键整理中英文间距和标点

中英混排最容易「脏」：英文词贴着中文、标点半角全角乱飞、段落空行忽有忽无。

TidyPost 可以一键整理间距、中文标点和段落空行，应用前还能先看对比，不满意就不点确认。

### 2. 标题、重点、列表，发前就能预览

用很简单的标记就能做出标题、重点、列表和引用，面板里即时预览纯文本效果。

你看到的，就是更接近发出去之后的样子（预览只模拟文字；图片、视频、链接卡片和实际折行仍以 X 为准）。

### 3. 按 X 规则算字，自动拆线程

X 对中文是按加权规则算字数的（常见说法是中文一个字大约占两个单位）。人工拆线程又慢又容易拆坏节奏。

TidyPost 按 X 的加权规则估算字数，长内容可以自动分成线程，也可以手动分条。拆完后一键写回发帖框，或逐条复制。插件不会替你点「发布」。

### 4. 草稿和历史版本，都在本地

草稿、历史版本、常用 @ 账号存在本机浏览器；部分设置和常用文字片段会走 Chrome 同步（你开了浏览器同步时才可能一起同步）。

排版在本地完成，不向开发者服务器上传内容，也没有内置统计或广告。

## 为什么说「商店里几乎没同款」

Chrome 应用商店里，单独做空格、单独做线程拆分、单独做格式化的工具都有。

但把这几件事放在一起、又专门照顾中文发帖体验的组合，并不多见：

- **中文整理**（间距、标点、空行）
- **按 X 规则拆线程**
- **发前预览**
- **本地草稿**
- **直接在发帖框里用**（不用另开一堆网页工具来回粘贴）

免费、公开上架，直接装就能用。

## 怎么开始

1. 打开 Chrome 应用商店安装 [推文排版 TidyPost](https://chromewebstore.google.com/detail/hngllgbockoahjngmhjcddcnnggjifba)
2. 打开 [x.com](https://x.com)，进入发帖框
3. 打开插件面板，粘贴或输入内容，整理、预览、拆线程，再写回发帖框

装完记得刷新一下 X 页面。
